Open-source research loop

Give it a topic.
Get a protocol someone else can run.

FarField searches related work, drafts a testable hypothesis, registers a two-arm experiment before seeing the numbers, and writes RESEARCH_PACKET.md. The model drafts hypotheses and scripts. Graph lookup, text checks, dataset binding, and the arithmetic on the two arms are ordinary Python. A result on made-up data can only weaken a claim. Confirmation needs a frozen dataset that matches the claim, then a rerun of the same experiment on this machine.

How a run works

Same loop every time. No extra packages.

01

Topic

You type a research question in your own words.

02

Search

The system pulls papers and samples concept pairs that are not already local neighbors.

03

Hypothesis

The model writes a claim, a mechanism, and a prediction.

04

Screening

Code drops pairs the graph already contains and drafts that fail the text checks.

05

Experiment

Both arms call the same metric and differ by one flag, on frozen data when a matching set exists.

06

Protocol

What remains is written to RESEARCH_PACKET.md and protocol.json.

Advanced options
TriesHow many concept groups

A cap, not a quota. By default we stop once a runnable protocol exists.

DraftsDrafts per group

Extra drafts compete; only the best one is kept. This is not a new search.

StopWhen to stop

Stop at a protocol after screening and experiment. Full budget is for comparison runs.

AssumptionsAlso question usual assumptions

This does not mix two fields. It asks whether this field’s usual assumption is wrong. Same screening and experiment still apply.

PolishPolish the write-up

Off by default. Changes wording only, not the hypothesis or the numbers.

ExperimentIf the experiment fails

Rewrite the script if it cannot run. Re-register the experiment if the two arms do not separate. Stop on support or weaken — never rewrite until support appears.

RewriteIf screening fails

Only rewrite the claim after a text-check failure. If the pair is already in the graph, or no matching data exists, wording will not paper over it.

Model and API

Changing the model only affects drafting quality. Whether two concepts were already combined is decided by the graph and search, not by the model’s vote.

Previous runs

Replay only reads the saved record. It does not call the model.
