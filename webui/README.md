# Console page

The page served by `scripts/console.py` at http://localhost:8765/. Keep the folder name `webui/`; the console already loads this path.

`index.html` plus `i18n.js`. Do not open the HTML as a `file://` page — `/i18n.js` and `/api/*` only exist on the console. The default bind is `127.0.0.1`.

A product landing page: topic in, protocol out. English / 中文 toggle, advanced options collapsed, short guidance on the empty state and after a run.

本目录是控制台静态页。文件夹名保持 `webui/`。不要用文件协议直接打开。
